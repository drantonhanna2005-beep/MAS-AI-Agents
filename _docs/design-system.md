# نظام التصميم — MAS AI Agents

> مرجع موحّد للألوان والخطوط والمسافات والحركة، مأخوذ من الواجهة الحالية نفسها
> (`web/style.css` + `web/avatar.css`) حتى لا يخترع كل عضو مقاسات جديدة.
>
> آخر تحديث: 2026-11 — الفريق الثاني (Frontend & Multimedia).

---

## 1. المصدر الواحد

كل المقاسات معرّفة مرة واحدة في `web/style.css` داخل `:root`، وأي مكوّن جديد
يقرأ منها بدل الأرقام المباشرة:

```css
/* Type scale */
--fs-10 … --fs-34        /* أحجام الخطوط */
/* Spacing (4pt) */
--sp-1:4px … --sp-10:40px
/* Radii */
--radius-xs:8px --radius-md:12px --radius-lg:20px --radius-pill:999px
/* Motion */
--dur-1:140ms --dur-2:220ms --dur-3:320ms --ease-out
/* Layers */
--z-composer:16 --z-nav:18 --z-avatar:45 --z-modal:80 --z-toast:100
```

## 3. الخط

- العائلة: **Cairo** (400/500/600/700/800) ثم `Segoe UI, Tahoma, sans-serif` كبديل.
- الأرقام في العدّادات والوقت: `font-variant-numeric: tabular-nums`.
- لا تُستخدم أوزان أقل من 400، ولا أحجام أقل من 10px.

### سلّم الأحجام

| Token | px | الاستخدام |
|---|---|---|
| `--fs-10` | 10 | تسميات دقيقة (micro)، عدّاد المكتبة |
| `--fs-11` | 11 | تلميحات، meta، وسوم صغيرة |
| `--fs-12` | 12 | أزرار ثانوية، نص مساعد |
| `--fs-13` | 13 | واجهة عامة (القائمة، الإعدادات، البطاقات) |
| `--fs-14` | 14 | نص الرسائل والمحادثة |
| `--fs-15` | 15 | عناوين فرعية |
| `--fs-16` | 16 | عناوين المودال |
| `--fs-18` | 18 | عناوين الأقسام |
| `--fs-21` | 21 | عنوان صفحة |
| `--fs-23` | 23 | أيقونات/إيموجي كبيرة |
| `--fs-30` | 30 | أرقام النتائج (GPA) |
| `--fs-34` | 34 | رقم الدرجة الكبير (CV) |

قبل التوحيد كان في **22 حجمًا** مختلفًا (9.5 / 10.5 / 10.8 / 11.5 / 12.5 / 13.2 / 13.5 / 14.3 / 14.5 / 14.8 / 15.5 / 17 …).
بعد التوحيد: **12 حجمًا** فقط، وكلها عبر tokens (86 استخدامًا).

## 4. المسافات

سلّم 4pt: `4 · 8 · 12 · 16 · 20 · 24 · 32 · 40`.

- داخل البطاقة: `12–16px`.
- بين البطاقات: `12px` (شبكة) و`22px` بين الرسائل.
- هوامش الصفحة: `22px` أفقي على الديسكتوب، `14px` على الموبايل.
- لا تُستخدم قيم مثل 7px أو 13px إلا داخل مكوّن دقيق (أيقونة/حد).

## 5. الحواف والظلال

| Token | القيمة | الاستخدام |
|---|---|---|
| `--radius-xs` | 8px | أزرار صغيرة، وسوم |
| `--radius-sm` | 11px | حقول، عناصر قائمة |
| `--radius-md` | 12px | بطاقات داخلية، مودالات صغيرة |
| `--radius` | 16px | البطاقات الأساسية |
| `--radius-lg` | 20px | المودال، لوحة الـ avatar |
| `--radius-pill` | 999px | أزرار دائرية/شرائح |

- الظل الأساسي `--shadow` للعناصر الطافية (avatar، مودال، شريط مشاركة).
- الظل الخفيف `--shadow-sm` للبطاقات عند hover فقط.
- حدود 1px بلون `--line` هي الفاصل الأساسي؛ الظل ليس بديلًا عن الحدود.

## 6. الحركة

| Token | القيمة | الاستخدام |
|---|---|---|
| `--dur-1` | 140ms | hover/الضغط |
| `--dur-2` | 220ms | فتح/إغلاق، تبويب |
| `--dur-3` | 320ms | دخول البطاقات والمودال |
| `--ease-out` | `cubic-bezier(.2,.8,.2,1)` | كل الحركات |

قواعد:
- لا تُحرَّك `opacity` لعنصر كامل يحتوي فيديو/نصًا أساسيًا؛ استخدم `transform` فقط.
- أي حركة يجب أن تحترم `prefers-reduced-motion` (القاعدة العامة موجودة في `style.css`).
- لا حركة أطول من 320ms في الواجهة الأساسية.

## 8. قواعد RTL / LTR

- استخدم الخصائص المنطقية دائمًا: `margin-inline`, `padding-inline`, `inset-inline-start/end`,
  `border-inline-start`.
- العناصر التي يجب أن تبقى LTR حتى في الواجهة العربية: الكود، روابط الأكواد،
  **أدوات مشغل الفيديو** (تشغيل ← شريط ← صوت ← ملء الشاشة).
- الأرقام والوقت: `tabular-nums` مع `direction: ltr` داخل العدّاد فقط.
- الاختبار المطلوب لأي مكوّن: عربي RTL + إنجليزي LTR + دارك + لايت.

## 10. ما تم تغييره في هذه الجولة

| البند | قبل | بعد |
|---|---|---|
| أحجام الخطوط | 22 قيمة مختلفة | 12 token |
| ألوان النجاح | `#22c55e` / `#16a34a` / `#15803d` | `var(--ok)` |
| z-index | أرقام حرة | 5 tokens |
| شفافية سطح الـ avatar | `color-mix` شفاف + blur | سطح صلب `var(--card)` لضمان التباين |
| حركة دخول الـ avatar | `opacity` من 0 | `transform` فقط (لا شفافية عالقة) |

> ملاحظة: التغييرات مقصورة على القيم، ولم تُغيَّر أي بنية HTML أو أسماء كلاسات قائمة،
> حتى لا تتعارض مع عمل بقية الفرق.
